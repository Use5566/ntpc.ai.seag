使用說明
  1. 貼上逐字稿或匯入 UTF-8 TXT。
  2. 指定遮蔽詞彙，逐字檢查安全預覽後確認。
  3. 下載 AI 整理任務，在自己選用的 AI 服務處理，再貼回 JSON。這個前台本身不呼叫 AI。
  4. 核對正文、metadata、完全捨棄的內容與問題，完成必要的人工補充。
  5. 確認後下載純文字正式稿。下一階段才會串接資料庫。
本頁不使用雲端儲存、瀏覽器自動儲存或追蹤服務。關閉分頁會失去未下載的內容。可以在檢閱階段下載工作稿，之後使用「匯入工作稿」續編。
API Key 不應貼進逐字稿，也不應提交到 GitHub。將來的自動 AI 功能必須由有登入驗證的後端代理。
